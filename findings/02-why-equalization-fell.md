From 2019-20 to {{ f.aid_year }}, formula need rose {{ f.need_gain }} ({{ f.need_growth }}). School adjusted valuation changed {{ f.sav_growth }}, which at the $1.00 local effort rate added {{ f.le_gain }} to resources. Resources grew faster than need, so equalization aid fell from {{ f.eq0 }} to {{ f.eq1 }}, and the systems receiving it from {{ f.equalized0 }} to {{ f.equalized1 }}.

Foundation aid paid {{ f.found_total }} in {{ f.aid_year }}, but 60% of it counts as a resource, and in a system that receives equalization aid that part replaces equalization aid dollar for dollar. It added {{ f.found_net }} to total aid; the other {{ f.found_replaced }} replaced equalization aid. For the {{ f.equalized1 }} systems that still receive equalization aid, {{ f.found_eq_share }} of their foundation aid was new money ({{ f.found_eq_net }} of {{ f.found_eq_total }}).

For {{ f.n_left_le }} of the {{ f.n_left }}, local effort grew more than need. {{ f.n_left_flip }} would still receive equalization aid if foundation aid were not counted as a resource.
